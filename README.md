# Раскрой для Android

Готовый проект приложения. Внутри окно WebView с тем же приложением, что и на компьютере.

* Экран поворачивается в любую сторону (если в телефоне включён автоповорот), расчёт при повороте не сбрасывается.
* Масштаб подстраивается под диагональ устройства: на телефоне интерфейс в натуральную величину, на планшете крупнее (до 1,5 раза). Страница всегда занимает весь экран.
* Экспорт в PDF, JPG и Word открывает системное окно «Сохранить как». Список из корзины копируется в буфер обмена.
* При первом запуске комнат нет, тема тёмная. Ctrl+Z / Ctrl+Y (с клавиатурой) отменяют и возвращают действия.
* Работает без интернета, данные хранятся на устройстве.

## Как получить APK

### Вариант 1. Android Studio

1. Откройте Android Studio и выберите File → Open, укажите эту папку. Дождитесь окончания синхронизации Gradle.
2. Меню Build → Build Bundle(s) / APK(s) → Build APK(s).
3. Нажмите «locate» во всплывающем сообщении, файл лежит в `app/build/outputs/apk/debug/app-debug.apk`.
4. Скопируйте APK на телефон и откройте его. Система попросит разрешить установку из этого источника.

### Вариант 2. Без установки программ, через GitHub

1. Создайте на github.com пустой репозиторий и загрузите в него содержимое этой папки (вместе со скрытой папкой `.github`).
2. Откройте вкладку Actions, выберите «Сборка APK» и нажмите Run workflow.
3. Через несколько минут в результатах запуска появится архив `Raskroy-apk` с готовым `app-release.apk`.

APK подписан отладочным ключом, этого достаточно для установки на свои устройства. Для публикации в Google Play нужен собственный ключ.
